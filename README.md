# Система обліку оренди обладнання

## Короткий опис
Цей проєкт — це система для автоматизації процесів здачі техніки та обладнання в оренду. Додаток дозволяє вести облік наявного інвентарю, відстежувати його поточний статус (доступно, в оренді, на обслуговуванні) та управляти клієнтськими бронюваннями в режимі реального часу. Мета проєкту — спростити контроль за рухом обладнання та мінімізувати ризики втрати чи прострочення повернення.

## Ролі користувачів

У системі передбачено кілька рівнів доступу (ролей) для різних типів користувачів:

* **Адміністратор (Admin)**
  Має повний контроль над системою. Може додавати або видаляти обладнання, редагувати його характеристики, управляти обліковими записами співробітників і клієнтів, а також переглядати загальну статистику оренди.

* **Менеджер / Оператор (Staff)**
  Відповідає за щоденну роботу з клієнтами. Оформлює видачу та повернення обладнання, змінює його статуси, фіксує дефекти після повернення та веде облік поточних активних оренд.

* **Клієнт (Client)**
  Авторизований користувач, який може переглядати каталог вільного обладнання, створювати запити на бронювання, бачити терміни своїх активних оренд та історію попередніх замовлень.
